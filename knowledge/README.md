# Knowledge documents

Documents the **Documents** tab (and `POST /documents/ask`) searches and cites.

- `sfa/` — a **synthetic, fictional** document set for the pharma field-force test case (company SOPs, policies and product sheets). Names, products, numbers and rules are invented for testing; they describe no real company, product or regulation.
- The project's own documentation (`README.md`, `docs/*.md`) is indexed too.

Like `domains/`, this folder is data: it is the only place, besides domain files, where domain words appear. Add `.md` or `.txt` files here (or upload them in the Documents tab) and rebuild the index.
